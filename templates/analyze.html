Pipeline

How it works

Three stages turn a raw binary into an actionable classification.

1. Upload

Drop any suspicious binary. We extract SHA-256, MD5, and SHA-1 hashes, compute Shannon entropy, and identify the file type — all locally.

2. Visual conversion

Raw bytes are reshaped into a 64×64 grayscale image. This visual fingerprint captures structural patterns unique to each malware family.

3. AI classification

Three independent neural networks (CNN, BiLSTM, Hybrid) vote on the family. A consensus verdict is produced along with per-model confidence scores.

What we detect

Our ensemble covers 26 malware families spanning multiple threat categories:

Ransomware Trojans Worms Adware Packers Botnets

Trained on 9,328 samples from the MalImg benchmark dataset with 90–92% accuracy.

Supported formats
  • EXE — Windows executables
  • DLL — Dynamic libraries
  • ELF — Linux binaries
  • PDF — Portable documents
  • SYS — Kernel drivers
  • APK — Android packages
  • SCR — Screensavers
  • Any — Raw binary blobs

Privacy: All processing is performed locally. Files are never transmitted to external servers.
