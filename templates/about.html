About MalVision

Malware analysis, made more legible.

How our visual classification workflow turns an opaque binary into an actionable signal.

Project background

MalVision is an AI-powered malware classification platform designed to detect and categorize malicious binaries without relying on traditional signature-based detection. By treating binaries as grayscale images, we leverage the power of deep learning to recognize the visual patterns and textures inherent in different malware families.

The models were trained on the widely recognized MalImg dataset, consisting of 8,404 training samples and 924 validation samples across 26 distinct malware families.

Model Architectures

CNN

A Convolutional Neural Network (CNN) architecture designed to extract spatial features and texture patterns directly from the 2D grayscale image representation of the binary.

BiLSTM

A Bidirectional Long Short-Term Memory (BiLSTM) network that treats the image as a sequence of bytes, capturing long-range dependencies and structural flow in the binary data.

Hybrid CNN-LSTM

A dual-branch architecture that combines the spatial feature extraction of a CNN with the sequential memory capabilities of a BiLSTM, fusing the representations for robust classification.

Training configuration

  • Image Size: 64x64 pixels
  • Batch Size: 32
  • Optimizer: Adam
  • Regularization: Early stopping, Dropout layers
